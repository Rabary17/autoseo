Vue synthétique des ébauches

Structure commune à tous les moteurs

  • Métadonnées : Silo, auteur, longueur estimée
  • Données factuelles : Prix, tarifs, coûts, spécifications (de la base P2)
  • Structure contenu : Titres H2/H3, listes, tableaux, FAQ
  • Sources citées : Vroomly, constructeurs, Sécurité routière, service-public.fr
  • Unicité garantie : Chaque article combine données + template unique par auteur

Comment le pipeline autopublish utilise ces moteurs

  1. Lire tracking-mots-cles.xlsx : récupère les clusters P1 (506 au total)
  2. Assigner moteur : M1 pour « Entretien », M2 pour « Pannes », etc.
  3. Charger données factuelles : P2 (prix vidange, codes OBD, modèles, etc.)
  4. Charger maillage P3 : liens hub/sous-hub/latéraux à injecter
  5. Rédaction Claude : Template moteur + données + mots-clés → article complet
  6. Relecture + gating : 9 règles vérifiées automatiquement
  7. Publication WordPress : Article + métadonnées + image + catégorie/tags

Points clés

Unicité à l'échelle

  • Chaque article combine : template éditorial + données factuelles + voix auteur → 0% duplication
  • Les ébauches ci-dessus sont des exemples de résultats finaux
  • À 10 000 articles, le coût moyen/article = ~5€ (vs 30–80€ rédacteur humain)
