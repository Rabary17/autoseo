🚀 Pipeline autopublish & infrastructure

Pipeline autopublish validé de bout en bout en CI (2026-07-17 soir)

Workflow test-e2e vert (6/6) : auth WordPress, génération Claude (Haiku articles / Sonnet hub+relecture), relecture obligatoire (a correctement rejeté un contenu test hors-sujet), sourcing image, écriture WordPress. 3 workflows GitHub Actions :

  • autopublish.yml — Hebdomadaire (lundi 6h) + workflow_dispatch --dry-run
  • daily-report.yml — Quotidien (e-mail de rapport)
  • test-e2e.yml — Manuel (validé vert)

Le pipeline est « armé » mais pas encore lancé : reste (a) brancher les 4 variables d'env Vercel vers le nouveau WP, (b) décision photos d'auteur (avatars neutres recommandés), (c) validation explicite de l'utilisateur avant le premier run réel (règle projet).

Frontend Next.js 15 — 100% fonctionnel
