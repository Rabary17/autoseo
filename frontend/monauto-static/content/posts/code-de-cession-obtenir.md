***Le code de cession se génère automatiquement dès que vous déclarez la vente de votre véhicule sur l'ANTS. Sans lui, l'acheteur ne peut pas mettre la carte grise à son nom.***

Vous venez de vendre votre voiture, le chèque est encaissé, les clés sont remises. Il reste une étape que beaucoup de vendeurs découvrent trop tard : générer le code de cession et le transmettre à l'acheteur. Sans ce code, il reste bloqué pour immatriculer le véhicule.

TL;DR : le code de cession s'obtient en déclarant la vente sur le site de l'ANTS. Il est valable 15 jours.

-   La déclaration de cession doit intervenir dans les **15 jours** suivant la vente, sous peine d'amende.
-   Le code apparaît immédiatement après validation, dans l'email de confirmation et sur votre compte ANTS.
-   Passé son délai de validité, seul le **vendeur** peut en regénérer un nouveau, pas l'acheteur.

## Pourquoi le code de cession est-il indispensable ?

Le code de cession sert de clé d'accès pour l'acheteur. Sans lui, impossible de lancer la demande de nouvelle carte grise sur le site de l'ANTS ou via un professionnel habilité. Cette suite de caractères prouve que la vente a bien été déclarée par le vendeur, et que le véhicule a changé de responsable sur le plan administratif.

Ce mécanisme protège d'abord le **vendeur**. Dès la déclaration de cession validée, vous n'êtes plus responsable des amendes ou infractions commises avec le véhicule, même si l'acheteur tarde à l'immatriculer à son nom. L'[article R322-4 du code de la route](/carte-grise-ants-demarches/) impose cette déclaration sous 15 jours, faute de quoi vous risquez une amende.

Sans cette démarche, difficile aussi d'assurer un changement de titulaire propre. Notre guide sur le [changement de titulaire de la carte grise](/changement-de-titulaire-carte-grise/) détaille la suite du parcours administratif, côté acheteur cette fois.

## Comment obtenir le code de cession sur l'ANTS ?

**Réponse directe** : le code de cession s'obtient en 10 minutes en déclarant la vente sur le site de l'ANTS, via FranceConnect ou un compte classique. Il apparaît immédiatement après validation du dossier, dans le récapitulatif et par email.

Voici le déroulé complet de la démarche :

1.  **Réunissez les documents.** Carte grise barrée et signée par vous et l'acheteur, pièce d'identité valide, [certificat de cession Cerfa n°15776](/certificat-cession-cerfa-15776/) rempli et signé par les deux parties.
2.  **Connectez-vous sur ants.gouv.fr.** Via FranceConnect (identifiants impots.gouv, Ameli ou La Poste) ou un compte ANTS classique créé avec une adresse email.
3.  **Choisissez « Vendre ou donner mon véhicule »**, puis « Déclarer la cession d'un véhicule ».
4.  **Renseignez le numéro d'immatriculation** et le numéro de formule de la carte grise. Vérifiez que la marque, le modèle et le type affichés correspondent bien au véhicule vendu.
5.  **Indiquez les coordonnées de l'acheteur** : nom, prénom, adresse et email. L'ANTS s'en sert pour le notifier de la déclaration.
6.  **Validez.** Un récapitulatif s'affiche à l'écran, suivi d'un email de confirmation.
7.  **Récupérez le code de cession**, dans l'email ou sur votre compte ANTS, et transmettez-le immédiatement à l'acheteur par SMS ou email.

Le traitement est quasi instantané avec FranceConnect. Sans ce mode de connexion, comptez plutôt deux à trois jours ouvrés avant de recevoir la confirmation complète.

## Code de cession expiré ou perdu : que faire ?

Le code reste valable **15 jours** après sa génération. Si l'acheteur ne l'utilise pas dans ce délai, il devient inutilisable sur le site de l'ANTS. Seul le vendeur, et non l'acheteur, peut en générer un nouveau depuis son compte ANTS.

| Situation | Qui agit | Démarche |
| --- | --- | --- |
| Code non utilisé après 15 jours | Vendeur | Se reconnecter sur son compte ANTS pour régénérer un nouveau code |
| Code perdu avant transmission | Vendeur | Retrouver l'email de confirmation ou consulter son espace ANTS |
| Acheteur n'a jamais reçu le code | Vendeur | Renvoyer le code manuellement, vérifier l'adresse email saisie |
| Vendeur injoignable | Acheteur | Contacter l'assistance ANTS avec le numéro de formule et la date du certificat barré |

Une adresse email mal orthographiée reste l'incident le plus fréquent. Vérifiez systématiquement la saisie avant de valider, cela évite une bonne partie des blocages signalés par les utilisateurs du service.

## Que risque-t-on en cas de retard de déclaration ?

Rater le délai de 15 jours expose à une amende forfaitaire, dont le montant augmente avec le retard accumulé.

| Délai de paiement | Montant de l'amende |
| --- | --- |
| Sous 15 jours (tarif minoré) | 90 € |
| Tarif normal | 135 € |
| Au-delà de 45 jours (tarif majoré) | 375 € |

Au-delà de l'amende, un retard prolonge aussi la période où vous restez exposé aux infractions commises avec le véhicule : radars, stationnement, voire délits plus graves, tant que la cession n'est pas enregistrée.

Pour régulariser rapidement : connectez-vous à votre compte ANTS, déclarez la cession sans attendre, et conservez l'email de confirmation comme preuve de bonne foi en cas de contrôle ultérieur.

## Cas particuliers : succession, donation, véhicule détruit

**Un véhicule hérité** doit d'abord être remis au nom de l'héritier avant toute revente. Les documents à réunir : certificat de décès, livret de famille complet et attestation signée par l'ensemble des héritiers en l'absence de litige. Notre guide sur la [carte grise après succession](/carte-grise-heritage-succession/) détaille cette étape préalable, souvent source de confusion.

**Une donation** suit une procédure presque identique à une vente. Vous déclarez la cession sur l'ANTS, puis transmettez le code au bénéficiaire. Seule différence notable : le certificat de cession doit mentionner « Donation » et non un prix de vente.

**Un véhicule promis à la destruction** nécessite aussi un code de cession, remis cette fois au centre VHU agréé qui prend en charge le véhicule. Notre article sur la [cession pour destruction](/cession-vehicule-pour-destruction/) détaille cette procédure spécifique, avec ses propres délais.

En cas de désaccord avec l'acheteur, notamment un refus de signer le certificat de cession, une mise en demeure par courrier recommandé reste la première étape. Sans signature des deux parties, l'ANTS rejette systématiquement la déclaration.

## Après l'obtention du code : les étapes suivantes

Une fois le code transmis, l'acheteur dispose d'**un mois** pour immatriculer le véhicule à son nom, comme le détaille notre guide sur le [délai pour la carte grise après achat](/delai-carte-grise-apres-achat/). Pendant cette période, vous n'êtes déjà plus responsable du véhicule sur le plan administratif.

Conservez malgré tout une copie du certificat de cession signé et l'email de confirmation ANTS pendant au moins **cinq ans**. Ces deux documents font foi en cas de litige ultérieur, notamment si un avis de contravention vous parvient par erreur après la vente.

Si vous vendez à un professionnel, demandez-lui une attestation de prise en charge de la déclaration. Beaucoup de garages et concessions s'occupent eux-mêmes de cette formalité au moment de la reprise, ce qui vous dispense de générer le code vous-même.

## Questions fréquentes

### Combien de temps le code de cession reste-t-il valable ?

15 jours à compter de sa génération. Passé ce délai, l'acheteur ne peut plus l'utiliser et le vendeur doit en générer un nouveau depuis son compte ANTS.

### Qui génère le code de cession, le vendeur ou l'acheteur ?

Seul le vendeur le génère, au moment où il déclare la cession sur le site de l'ANTS. L'acheteur ne peut pas le créer lui-même.

### Que faire si l'acheteur n'a jamais reçu le code ?

Vérifiez d'abord l'adresse email saisie lors de la déclaration. Si elle est correcte, retransmettez le code manuellement par SMS, il reste consultable sur votre compte ANTS tant qu'il n'a pas expiré.

### Quel document faut-il pour déclarer la cession et obtenir le code ?

La carte grise barrée et signée, une pièce d'identité valide, et le certificat de cession Cerfa n°15776 signé par le vendeur et l'acheteur.

### Risque-t-on une amende sans code de cession transmis ?

Le code en lui-même n'entraîne pas d'amende. C'est le retard de la déclaration de cession, au-delà de 15 jours après la vente, qui expose à une amende de 90 € à 375 €.

### Peut-on vendre un véhicule sans jamais obtenir de code de cession ?

Non. Sans déclaration de cession validée sur l'ANTS, aucun code n'est généré, et l'acheteur reste dans l'impossibilité d'immatriculer légalement le véhicule à son nom.
