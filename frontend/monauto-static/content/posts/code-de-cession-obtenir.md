## Pourquoi le code de cession est-il obligatoire ?

Dès que vous vendez ou donnez votre voiture, vous devez déclarer cette cession à l’ANTS. Cette démarche génère automatiquement un **code de cession**, un identifiant unique à 5 chiffres. Vous le transmettez ensuite à l’acheteur. Sans ce code, il ne peut pas immatriculer le véhicule à son nom.

C’est une sécurité pour vous. En effet, une fois la déclaration faite, vous n’êtes plus responsable du véhicule. Même s’il n’est pas encore réimmatriculé, la responsabilité vous est retirée. [L’article R322-4 du Code de la route](/carte-grise-demarches/changement-de-titulaire) précise que vous avez **15 jours** pour effectuer cette déclaration. Passé ce délai, vous risquez une amende forfaitaire de 135 €. Cependant, si vous payez sous 15 jours, cette amende est réduite à 90 €.

## Étapes pour obtenir le code de cession sur l’ANTS

La déclaration de cession se fait entièrement en ligne sur le site de l’ANTS. Voici les étapes à suivre :

1.  **Préparez les documents**. Vous aurez besoin de la carte grise du véhicule, barrée et signée par vous et l’acheteur. Il vous faudra aussi une pièce d’identité valide. Enfin, le certificat de cession (formulaire Cerfa n°15776\*02) doit être rempli et signé par les deux parties.
2.  **Connectez-vous à votre compte ANTS**. Si vous n’en avez pas, créez-en un avec votre adresse e-mail et un mot de passe. Vous pouvez aussi utiliser FranceConnect. Ainsi, vous vous connecterez avec vos identifiants Impots.gouv, Ameli, ou La Poste.
3.  **Accédez à la démarche**. Dans le menu, sélectionnez « Vendre ou donner mon véhicule ». Puis, choisissez « Déclarer la cession d’un véhicule ».
4.  **Renseignez les informations du véhicule**. Entrez le numéro d’immatriculation et le numéro de formule de la carte grise. Vérifiez ensuite que les données affichées (marque, modèle, type) correspondent bien à votre véhicule.
5.  **Saisissez les coordonnées de l’acheteur**. Indiquez son nom, prénom, adresse postale et e-mail. Ces informations sont indispensables. En effet, l’ANTS en a besoin pour notifier l’acheteur de la déclaration.
6.  **Validez la déclaration**. Après avoir vérifié toutes les informations, cliquez sur « Valider ». Un récapitulatif s’affiche alors. Vous recevrez aussi un e-mail de confirmation.
7.  **Récupérez le code de cession**. Vous le trouverez dans l’e-mail de confirmation ou directement sur votre compte ANTS. Transmettez-le immédiatement à l’acheteur par SMS ou e-mail.

Le code est valable **15 jours**. Par conséquent, si l’acheteur ne l’utilise pas dans ce délai, vous devrez recommencer la démarche pour en générer un nouveau.

## Que faire si vous avez dépassé le délai de 15 jours ?

Si vous n’avez pas déclaré la cession dans les 15 jours, vous risquez une amende. Voici ce que dit la réglementation :

Pour régulariser votre situation, suivez ces étapes :

-   Connectez-vous à votre compte ANTS et déclarez la cession **sans tarder**. Ainsi, vous limiterez les risques de majoration de l’amende.
-   Si vous recevez un avis d’amende, payez-la rapidement. Vous bénéficierez alors du tarif minoré (90 €).
-   Conservez une preuve de la déclaration. Par exemple, l’e-mail de confirmation de l’ANTS. Cela vous servira en cas de contrôle pour justifier de votre bonne foi.

## Cas particuliers : succession, donation, ou véhicule non roulant

La déclaration de cession s’applique aussi dans d’autres situations. Voici les démarches spécifiques à chaque cas.

### Véhicule en succession

Si vous héritez d’un véhicule, vous devez d’abord le mettre à votre nom. Ensuite, vous pourrez le vendre ou le donner. Voici les documents nécessaires :

-   Le certificat de décès du propriétaire.
-   Le livret de famille complet.
-   Une attestation signée par tous les héritiers. Cela s’applique si la succession est simple, sans testament ni litige.
-   Un justificatif de domicile.

Le coût de la nouvelle carte grise est d’environ **13,76 €**. Ce montant exclut les frais de succession éventuels. Une fois le véhicule à votre nom, vous pouvez effectuer la déclaration de cession classique pour le vendre. Pour [tout savoir sur les démarches liées à la carte grise](/carte-grise-demarches), consultez notre guide complet.

### Donation à un proche

La donation suit les mêmes règles que la vente. Vous devez déclarer la cession sur l’ANTS. Puis, vous fournissez le code de cession au bénéficiaire. La seule différence réside dans le certificat de cession. En effet, il doit mentionner « Donation » comme motif de la cession.

Si vous avez perdu le code de cession avant que l’acheteur ne l’utilise, connectez-vous à votre compte ANTS. Vous pourrez ainsi en générer un nouveau. Le code reste valable 15 jours. En cas de dépassement, l’acheteur devra contacter l’ANTS pour obtenir un duplicata.

### Véhicule non roulant ou destiné à la destruction

Même si vous vendez un véhicule pour pièces ou destruction, vous devez déclarer la cession. L’acheteur, souvent un professionnel de la casse, aura besoin du code de cession. Ainsi, il pourra justifier de la propriété du véhicule avant de le détruire.

En cas de litige avec l’acheteur, comme un refus de signer le certificat de cession, envoyez-lui une mise en demeure. Utilisez pour cela un courrier recommandé. Sans signature des deux parties, la déclaration sera rejetée par l’ANTS.

## Pour aller plus loin

Une fois la déclaration de cession effectuée, l’acheteur doit immatriculer le véhicule à son nom. Il dispose pour cela d’[un mois](/carte-grise-demarches/delai-carte-grise-apres-achat). Pendant ce temps, vous n’êtes plus responsable du véhicule. Cependant, il est recommandé de conserver une copie du certificat de cession. Conservez aussi l’e-mail de confirmation de l’ANTS pendant **5 ans**. Cela vous protégera en cas de litige.

Si vous vendez votre voiture à un professionnel, comme un garage ou une concession, celui-ci peut se charger des démarches pour vous. Dans ce cas, demandez-lui une attestation de prise en charge de la déclaration de cession. Ainsi, vous serez tranquille.

Pour éviter les erreurs courantes, vérifiez toujours les informations saisies. Par exemple, une adresse e-mail mal orthographiée peut poser problème. Si l’acheteur ne reçoit pas le code, refaites la déclaration avec la bonne adresse. Vous pouvez aussi lui transmettre le code manuellement par SMS.
