Code OBD P0420 : Catalyseur défaillant — Diagnostic et réparation

Silo : Pannes & diagnostic Auteur : Persona B (diagnosticien) Longueur : ~1 100 mots

Code P0420 — Signification

P0420 = "Catalyst System Efficiency Below Threshold"

Traduction : Le système catalytique est moins efficace que prévu. Le convertisseur catalytique ne nettoie plus assez les gaz d'échappement.

Gravité : CRITIQUE — Ne pas ignorer. Vous polluez davantage et risquez un refus contrôle technique. À réparer sous 2 semaines.

Causes classées par probabilité

1. Catalyseur encrassé (40 % des cas)
Symptômes : Manque de puissance, surconsommation carburant, secousses à l'accélération
Solution : Nettoyage catalyseur (100–300 €) ou remplacement si irréparable
2. Sonde lambda défaillante (35 %)
Symptômes : Accélération saccadée, voyant moteur flou
Coût remplacement : 150–400 € TTC (capteur + MO)
3. Fuite d'échappement (15 %)
Symptômes : Bruit renforcé moteur, odeur gaz
Coût : 50–200 € (joints, tuyaux)
4. Catalyseur volé (rare, 5 %)
Voiture à l'arrêt + brouhaha — catalyseur retiré dessous
Coût remplacement : 800–2 500 € (catalyseur OEM)

Procédure diagnostic

  1. Scanner OBD-II : Lire le code P0420 + codes associés (P0130, P0135)
  2. Sonde lambda : Tester tension sonde (doit osciller 0.1–0.9V)
  3. Analyse gaz échappement : Contrôler CO/HC avant/après catalyseur
  4. Inspection visuelle : Vérifier boîtier catalyseur (pas de résidu d'huile, pas de déformation)

Coûts réparation (2026)

Réparation Coût TTC
Nettoyage catalyseur 100–300 €
Sonde lambda (après-marché) 150–250 €
Catalyseur de remplacement 600–1 500 € (essence)
800–2 500 € (diesel)

FAQ

Q : Puis-je rouler avec le code P0420 ?

Oui, court terme (1–2 semaines). Mais : surconsommation carburant, refus CT possible, amende écologique probable. À réparer rapidement.

Q : Réinitialiser le code va-t-il le supprimer ?

Temporairement. Le code revient en 100–200 km si le problème persiste. Réparer d'abord.
