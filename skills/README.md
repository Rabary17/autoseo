# Skills — projet autoseo

Ce dossier contient les règles de travail pour ce projet, organisées par domaine. Tout agent IA (Claude, autre) qui reprend le projet doit lire ces fichiers avant d'agir dans le domaine concerné.

- [seo.md](seo.md) — structure, maillage interne, mots-clés, règles rédactionnelles, SEOPress
- [geo.md](geo.md) — optimisation pour les moteurs génératifs (IA) : structure, JSON-LD/schema
- [design.md](design.md) — direction artistique : épuré, rapide, typographie
- [developpement.md](developpement.md) — stack technique : WordPress (back) / Next.js ISR sur Vercel (front) — implémentation complète et testée dans [../docs/architecture-headless.md](../docs/architecture-headless.md)
- [wordpress-publication.md](wordpress-publication.md) — Gutenberg, catégories/tags/image à la une, auteurs, planification & gating de publication
- [redaction.md](redaction.md) — voix propre à chaque auteur (A à F), liste de contrôle pour ne pas sonner comme un LLM
- [gestion-de-projet.md](gestion-de-projet.md) — reprise de session, gestion des tokens, suivi des mots-clés

Voir aussi [../STATE.md](../STATE.md) pour l'état d'avancement courant (à lire en premier lors d'une reprise), et [../docs/architecture-autopublish.md](../docs/architecture-autopublish.md) pour le pipeline de publication automatisée (API Anthropic directe, GitHub Actions).
